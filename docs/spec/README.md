# Specification

**What the tool does, today.** Everything here is true of the binary in front of
you — nothing describes an unbuilt command, a planned flag, or a shape still
being argued. Those live in [`design/parked/`](../design/parked/).

| | |
|---|---|
| [api](api.md) | the command surface — every scope, action and flag |
| [storage](storage.md) | what a node is on disk, and how one is written |
| [git](git.md) | why git, and what happens without it |

Reasons stay beside the rules they justify. A rule without one reads as
arbitrary, and separating them means holding two files open to understand one
command — see [the line between design and spec](../design/README.md).

What each batch *decided*, as opposed to what the surface *is*, is in
[`batches/`](../batches/).
